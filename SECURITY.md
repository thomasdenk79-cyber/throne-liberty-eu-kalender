# Sicherheitsrichtlinie

## Unterstützte Version

Sicherheitskorrekturen werden für den aktuellen Stand auf `main` gepflegt.

## Meldung

Bitte Sicherheitsprobleme vertraulich über ein
[privates Security Advisory](https://github.com/thomasdenk79-cyber/throne-liberty-eu-kalender/security/advisories/new)
melden. Keine Exploit-Details, Tokens, personenbezogenen Daten oder internen
Informationen in öffentliche Issues schreiben.

Die Meldung sollte Auswirkung, Reproduktion und eine mögliche Abhilfe enthalten.
Der Repository-Owner entscheidet über Priorität, Veröffentlichung und Release.
